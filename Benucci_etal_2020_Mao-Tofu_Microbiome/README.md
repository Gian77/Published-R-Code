## 📂 Repository Structure

Files are kept under their original supplementary-file names to match the published paper.

```
├── code

├── functions
├── misc
├── LICENSE
├── README.md
├── Suppl_File_1_Supplementary Figures 1-5.pdf

```

## 🚀 Clone and Use
```
# clone the main repo
git clone https://github.com/Gian77/Published-R-Code.git

# get only the desired subrepo
svn export https://github.com/Gian77/Published-R-Code/tree/master/Benucci_etal_2020_Mao-Tofu_Microbiome

cd Benucci_etal_2020_Mao-Tofu_Microbiome
```
